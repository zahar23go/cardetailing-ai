# Чек-лист: ручная проверка ИИ-Финансиста в салоне

Проверять на **реальном** тенанте / демо-данных салона. Отмечать ✅ / ❌.

## Подготовка

- [ ] Войти как админ салона
- [ ] Есть завершённые записи за текущий месяц
- [ ] Есть расходы (аренда, зарплата, маркетинг и т.д.) с датами текущего месяца
- [ ] У услуг заполнены `price` и `cost_price` / `material_cost`

## 1. KPI и выручка

- [ ] **Дашборд** (`/dashboard`): «выручка сегодня» = сумма `completed` за сегодня
- [ ] **Дашборд**: «выручка месяц» = сумма `completed` с 1 числа
- [ ] **Финансы / P&L** (`/analytics/finances`): выручка совпадает с дашбордом (месяц)
- [ ] **Средний чек** = выручка / число завершённых записей (проверить калькулятором)
- [ ] Отменённые / pending **не** входят в выручку

## 2. Прибыль и маржа

- [ ] **Валовая прибыль** = выручка − сумма материалов по завершённым
- [ ] **Валовая маржа %** = валовая / выручка × 100
- [ ] **Чистая прибыль** = валовая − сумма расходов месяца
- [ ] **Чистая маржа %** = чистая / выручка × 100
- [ ] Маржа по услуге в каталоге: `((price − cost) / price) × 100`
- [ ] Цвет маржи в UI: ≥50% зелёный, ≥30% золото, иначе красный

## 3. Расходы и break-even

- [ ] Сумма расходов по категориям = итог месяца
- [ ] **Точка безубыточности** ≈ постоянные / ((выручка − материалы) / выручка)
- [ ] **Прогноз прибыли** = выручка − материалы − постоянные
- [ ] При росте категории >30% MoM появляется anomaly-инсайт
- [ ] Если аренда ≥25% выручки — предупреждение
- [ ] Если выручка/реклама <5 — «реклама неэффективна»; ≥10 — «работает»

## 4. Загрузка (теплокарта)

- [ ] Теплокарта показывает слоты 8:00–22:00, Пн–Вс
- [ ] В ячейке учтены статусы: completed, confirmed, in_progress, pending
- [ ] Более «горячие» ячейки соответствуют большему числу записей

## 5. Happy Hours / скидки по загрузке

- [ ] Пиковые часы группы (Пн–Пт / Сб / Вс) → предложение **0%**
- [ ] Слабая загрузка (~12–20% от пика) → 20–25%
- [ ] Средняя → 10–15%
- [ ] ROI правила: ≥20% «держать», 0–20% «пересмотреть», <0 «отключить»

## 6. Скидки по услугам (бухлогика)

- [ ] Услуги с высокой маржой (≥70%) и нормальным спросом **не** рекомендуются к скидке
- [ ] Просевшие по записям / низкомаржинальные — есть рекомендация
- [ ] На высокомаржинальных с просадкой объёма скидка ≤12%
- [ ] При высоком давлении постоянных расходов % на низкомаржинальных выше

## 7. ИИ-Финансист (чат)

- [ ] Открыть `/analytics/ai-financier`
- [ ] Вопрос: «Какая прибыль за месяц?» — ответ по шаблону АНАЛИЗ / ПРИЧИНА→ДЕЙСТВИЕ→ПРОГНОЗ / РЕКОМЕНДАЦИИ
- [ ] Цифры в ответе **не выдуманы** — совпадают с контекстом (выручка, записи, мастера)
- [ ] Вопрос: «Кто из мастеров эффективнее?» — использует фактические completed/revenue
- [ ] Без токена админа — 401/403
- [ ] Пустой вопрос — 422
